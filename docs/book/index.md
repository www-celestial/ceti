# Ceti

Ceti drives Firefox from Cesia, through WebDriver BiDi, the W3C protocol of browser automation: a test of a web
application, or a program that automates pages, opens a page, clicks, types, reads a text and captures the screen.

1. [Driving Firefox](guide.md): starting Firefox, its template profile and its permissions, pages and their user
   contexts, CSS selectors and
   the waits, clicks, typing and keys, reading the page, `Eval`, screenshots, errors, several pages at once, tests, and
   why no Firefox is left behind.
2. [Speed](speed.md): what each step costs, beside the raw protocol, what the template profile saves, and how it was
   measured.

The reference of the package, every public name with its parameters, is under [Reference](ref/index.html).
